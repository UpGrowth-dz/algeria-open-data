# Algeria Open Data

Reference datasets on Algerian business administration, published as open data by [UpGrowth](https://www.upgrowth.dz), Algiers.

## Datasets

| Dataset | Records | Coverage |
|---|---|---|
| CNRC commercial activity nomenclature | 2,134 codes | French, English, Arabic |
| ANAE auto-entrepreneur activities | 1,491 activities | French, English, Arabic |
| Journal Officiel archive index | 5,288 issues | 1962 to 2026 |
| Journal Officiel reference index | 2,017 issues | 2002 to 2026 |
| Wilayas | 58 | Administrative contact points |
| Customs tariff sections and chapters | 96 | French, English, Arabic |

## Notes

The Journal Officiel PDFs remain on the official portal at joradp.dz. These datasets index their locations; they do not redistribute the documents. Every PDF link in the archive index was requested individually against joradp.dz and is recorded only where the server returned a PDF.

English labels are UpGrowth translations provided for search and comparison. They carry no official status. Algerian nomenclatures are amended by regulatory text, so verify against the current official source before relying on any single code for a live filing.
